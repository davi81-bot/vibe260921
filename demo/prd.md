## 1. 배경 및 목적

건축가 윤현석의 전문성과 작업물을 소개하는 개인 프로필 웹사이트를 만든다. 윤현석은 건축가로서 **설계 자동화**를 주력 분야로 하며, 이 사이트는 다음 목적을 가진다.

- **전문성 전달**: 건축 설계와 자동화(코드·알고리즘)를 함께 다루는 건축가라는 정체성을 명확히 보여준다.
- **신뢰 형성**: 프로젝트와 결과물(사례)로 역량을 증명한다.
- **문의 유도**: 협업·의뢰·강연·채용 문의가 이메일로 자연스럽게 이어지게 한다.

## 2. 목표와 성공 지표

| 목표 | 지표 (출시 후 3개월 기준, 초안) |
|---|---|
| 방문자가 "무엇을 하는 사람인지" 즉시 이해 | 첫 화면 이탈률 60% 이하 |
| 프로젝트 열람 | 방문자당 프로젝트 상세 1회 이상 조회 비율 40% 이상 |
| 문의 전환 | 월 문의 메일 수 (목표치는 본인이 확정) |
| 접근성·성능 | Lighthouse 성능/접근성/SEO 각 90점 이상 |

> 수치는 초기 가정이며 운영하면서 조정한다.

## 3. 타깃 사용자

| 사용자 | 필요 | 사이트에서 하는 행동 |
|---|---|---|
| 건축주·개발사 | 설계 역량과 신뢰 확인 | 프로젝트 확인 → 이메일 문의 |
| 설계사무소·시공사 | 협업 파트너, 자동화 도입 상담 | 서비스·프로젝트 확인 → 협업 제안 |
| 채용 담당자·동료 건축가 | 기술 역량 파악 | 이력·기술 스택 확인 |
| 강연·미디어 관계자 | 전문 분야, 프로필 사진·소개문 확보 | 소개 확인 → 섭외 문의 |

## 4. 핵심 메시지

> 건축가 윤현석 — 설계 자동화로 설계의 반복을 줄이고, 더 나은 설계에 시간을 쓰게 합니다.

(문구는 초안. 본인 톤에 맞게 수정)

## 5. 정보 구조 (IA)

```
Home
├─ About        소개 · 이력 · 철학
├─ Work         프로젝트 목록
│   └─ Project  프로젝트 상세
├─ Expertise    설계 자동화 (서비스/역량/도구)
├─ Contact      문의
└─ (선택) Journal  글·노트
```

## 6. 기능 요구사항

우선순위: **P0** 출시 필수 / **P1** 출시 후 빠르게 / **P2** 여유 시

### 6.1 Home (P0)
- 히어로: 이름, 직함(건축가), 한 줄 소개, 대표 이미지 또는 대표 프로젝트
- 전문 분야 요약: 설계 자동화
- 대표 프로젝트 3~4개 카드
- 문의(Contact) CTA 버튼

### 6.2 About (P0)
- 프로필 사진, 소개문(짧은 버전/긴 버전)
- 이력: 학력·경력·수상·자격 (건축사 등 보유 시)
- 설계 철학 / 작업 방식
- 이력서(PDF) 다운로드 (P1)

### 6.3 Work / Project (P0)
- 프로젝트 목록: 썸네일, 제목, 연도, 유형(건축 설계 / 자동화 / 연구), 태그 필터 (필터 P1)
- 프로젝트 상세: 개요, 역할, 기간, 규모·위치, 이미지 갤러리, 도면·다이어그램, 사용 기술, 결과(시간 절감 등 정량 성과)
- 이전/다음 프로젝트 이동

### 6.4 Expertise: 설계 자동화 (P0)
- 무엇을 자동화하는가: 예) 반복 도면 작업, 물량·면적 산출, 법규 검토, 대안 생성, BIM 데이터 처리
- 접근 방식: 문제 정의 → 워크플로 설계 → 도구 개발 → 검증 → 팀 도입
- 사용 도구·기술 스택 (Grasshopper, Revit API/Dynamo, Python 등 실제 사용하는 것만 기재)
- 협업 방식과 제공 서비스 (컨설팅, 도구 개발, 교육)
- 전/후 비교 사례(예: 작업 시간 변화)를 시각 자료로 제시 (P1)

### 6.5 Contact (P0)
- 이메일 주소 노출 및 `mailto:` 링크: **davidoff1126@gmail.com**
- 문의 폼 (P1): 이름, 이메일, 문의 유형, 내용 → 이메일 전달
- 스팸 방지 (P1): 허니팟 또는 reCAPTCHA
- 소셜/포트폴리오 링크 (LinkedIn, GitHub 등, 보유 시) (P1)

### 6.6 공통 (P0)
- 반응형 (모바일·태블릿·데스크톱)
- 공통 헤더(내비게이션)·푸터(연락처, 저작권)
- SEO 메타 태그, Open Graph 이미지, sitemap.xml
- 국문 사이트 우선, 영문 버전 (P2)
- 다크 모드 (P2)

### 6.7 Journal (P2)
- 설계 자동화 관련 글·튜토리얼·노트 (마크다운 기반)

## 7. 비기능 요구사항

- **성능**: 이미지 최적화(WebP/AVIF, lazy loading), LCP 2.5초 이내
- **접근성**: WCAG 2.1 AA — 대체 텍스트, 키보드 탐색, 명도 대비
- **브라우저**: 최신 Chrome, Edge, Safari, Firefox 및 모바일 브라우저
- **보안·개인정보**: HTTPS, 문의 폼 수집 정보 최소화 및 안내 문구
- **유지보수**: 프로젝트를 코드 수정 없이 추가할 수 있는 구조 (콘텐츠 파일/CMS)

## 8. 디자인 방향 (초안)

- 건축가 포트폴리오답게 **이미지·도면 중심**, 여백이 넉넉한 미니멀 레이아웃
- 절제된 색상 (흑백·회색 + 포인트 1색), 가독성 좋은 한글 서체
- 설계 자동화 분야를 드러내는 요소: 알고리즘 다이어그램, 파라메트릭 형태 이미지 등
- 참고 레퍼런스는 본인이 선호하는 건축가/스튜디오 사이트를 추후 추가

## 9. 기술 방향 (제안)

| 옵션 | 설명 | 적합한 경우 |
|---|---|---|
| **A. 정적 사이트 (HTML/CSS/JS)** | 프레임워크 없이 직접 작성, GitHub Pages·Netlify 배포 | 페이지 수가 적고 단순하게 시작 (권장) |
| B. Astro / Next.js + 마크다운 | 프로젝트를 마크다운으로 관리 | 프로젝트·글이 늘어날 예정 |
| C. 노코드(Framer, Wix 등) | 빠른 제작 | 코딩 없이 운영하고 싶을 때 |

- 초기 권장: **A안**으로 MVP를 만들고, 콘텐츠가 늘면 B안으로 이전
- 문의 폼은 Formspree/Netlify Forms 등 서버리스 서비스 사용
- 도메인: 본인 이름 기반 도메인 검토 (예: 이름.com)

## 10. 필요한 콘텐츠 (윤현석 님 준비 사항)

아래는 사이트에 들어갈 사실 정보이며, 현재 확정된 것은 이름·이메일·주 분야뿐이다. 나머지는 준비 후 채운다.

- [ ] 프로필 사진 (고해상도)
- [ ] 소개문 (100자 / 500자 버전)
- [ ] 이력: 학력, 경력, 수상, 자격
- [ ] 대표 프로젝트 3~6개: 이미지, 설명, 역할, 성과
- [ ] 설계 자동화 사례와 사용 기술
- [ ] 외부 링크: LinkedIn, GitHub 등
- [ ] 이력서 PDF (선택)
- [ ] 공개 가능 여부 확인: 프로젝트 이미지 사용 허락 (발주처·소속 사무소 등)
